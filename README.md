# HA-DETR

## HA-DETR: A Model for Personnel Operation Safety Hazard Detection in Industrial Scenarios

This repository is intended to host the official implementation of HA-DETR, an improved RT-DETR-based object detection model for personnel operation safety hazard detection in complex industrial environments.

## Code and Model Weights

The source code, model implementation, training and evaluation scripts, experimental configurations, and trained model weights will be publicly released upon acceptance of the associated paper.

## Current Status

The repository is currently under preparation. The implementation and trained model weights are not yet publicly available.

## Dataset

The experiments involve the IPSHD, SHEL5K, and Construction-PPE datasets. Relevant dataset configurations and preprocessing details will be provided to facilitate reproducibility.
